# 📖 راهنمای کاربر: سیستم فیلتر یکپارچه مقالات

## 🎯 معرفی

سیستم فیلتر یکپارچه به شما اجازه می‌دهد تا مقالات را بر اساس معیارهای مختلف فیلتر کنید:
- ⏱️ **مدت زمان مطالعه** (0-60 دقیقه)
- 📊 **سطح دشواری** (مبتدی، متوسط، حرفه‌ای، تخصصی)
- 🔬 **نیاز به تمرین عملی** (دارد، ندارد)
- 📄 **نوع پست** (آموزشی، مقاله، اسکریپت، خبر، دستورالعمل، معرفی، ابزار)

---

## 🚀 نحوه استفاده

### مرحله 1: باز کردن فیلترها

1. **پیدا کردن دکمه فیلتر**
   - در پایین سمت **راست** صفحه یک دکمه شناور سبز رنگ با متن "🔧 فیلتر" وجود دارد
   - این دکمه در **همه صفحات لیست مقالات** (network، cyber-security، all-articles، ...) نمایش داده می‌شود

2. **کلیک روی دکمه**
   - با کلیک روی دکمه، **پنجره فیلتر** باز می‌شود
   - در Desktop: پنجره مرکزی با عرض متوسط
   - در Mobile/Tablet: پنجره تمام صفحه از پایین می‌آید

### مرحله 2: انتخاب فیلترها

#### ⏱️ فیلتر مدت زمان مطالعه
```
┌─────────────────────────────┐
│ ⏱️ مدت زمان مطالعه          │
│                             │
│ 0 ━━━━●━━━━━━━━━━━━━ 60    │
│       ↑                     │
│   محدوده زمان              │
└─────────────────────────────┘
```
- دو اسلایدر برای تعیین **حداقل** و **حداکثر** زمان
- مثال: 10-30 دقیقه = فقط مقالاتی که 10 تا 30 دقیقه طول می‌کشند

#### 📊 فیلتر سطح دشواری
```
☑️ مبتدی
☑️ متوسط
☑️ حرفه‌ای
☑️ تخصصی
```
- می‌توانید یک یا چند سطح را انتخاب کنید
- مثال: فقط "مبتدی" = فقط مقالات مبتدی نمایش داده شوند

#### 🔬 فیلتر نیاز به تمرین عملی
```
☑️ دارد
☑️ ندارد
```
- "دارد" = مقالاتی که نیاز به آزمایشگاه دارند
- "ندارد" = مقالات نظری بدون نیاز به تمرین

#### 📄 فیلتر نوع پست
```
☑️ آموزشی
☑️ مقاله
☑️ اسکریپت
☑️ خبر
☑️ دستور العمل
☑️ معرفی
☑️ ابزار
```
- می‌توانید یک یا چند نوع را انتخاب کنید

### مرحله 3: اعمال فیلتر

```
┌──────────────────────────────┐
│ ✅ اعمال فیلتر  |  🔄 بازنشانی │
└──────────────────────────────┘
```

- **✅ اعمال فیلتر**: 
  - فیلترها روی مقالات اعمال می‌شود
  - پنجره فیلتر بسته می‌شود
  - مقالات فیلتر شده نمایش داده می‌شوند
  - تعداد نتایج نمایش داده می‌شود

- **🔄 بازنشانی**:
  - همه فیلترها به حالت پیش‌فرض بازمی‌گردند
  - همه مقالات نمایش داده می‌شوند

### مرحله 4: بستن پنجره

4 روش برای بستن:
1. ✅ کلیک روی "اعمال فیلتر"
2. ❌ کلیک روی دکمه × در بالای پنجره
3. 🖱️ کلیک روی پس‌زمینه تیره
4. ⌨️ فشردن کلید ESC

## 💡 نکات کاربردی

### 1. ترکیب فیلترها
می‌توانید چند فیلتر را با هم ترکیب کنید:
```
مثال:
- زمان: 10-20 دقیقه
- سطح: مبتدی
- Lab: ندارد
- نوع: آموزشی

نتیجه: مقالات آموزشی مبتدی که 10-20 دقیقه زمان برند و نیاز به Lab نداشته باشند
```

### 2. فیلتر سریع
```
مبتدی‌ها:
✅ سطح: مبتدی
✅ زمان: 0-15 دقیقه
✅ Lab: ندارد

حرفه‌ای‌ها:
✅ سطح: حرفه‌ای، تخصصی
✅ Lab: دارد
✅ نوع: آموزشی
```

### 3. مشاهده همه
برای مشاهده همه مقالات:
1. کلیک روی "بازنشانی"
2. یا انتخاب همه گزینه‌ها در هر فیلتر

### 4. نتیجه خالی
اگر پیام "هیچ مقاله‌ای یافت نشد" دیدید:
```
┌─────────────────────────┐
│        🔍               │
│  هیچ مقاله‌ای یافت نشد  │
│  لطفاً فیلترها را       │
│  تغییر دهید            │
└─────────────────────────┘
```
- فیلترها را کمی گسترده‌تر کنید
- یا روی "بازنشانی" کلیک کنید

## ❓ سوالات متداول

### س1: چرا دکمه فیلتر نمایش داده نمی‌شود؟
**ج**: دکمه فقط در صفحات لیست مقالات نمایش داده می‌شود:
- ✅ /network/
- ✅ /cyber-security/
- ✅ /all-articles/
- ❌ صفحه اصلی (/)
- ❌ صفحات تک مقاله

### س2: آیا فیلترها ذخیره می‌شوند؟
**ج**: فیلترها در طول جلسه فعلی حفظ می‌شوند. بعد از refresh صفحه، به حالت پیش‌فرض بازمی‌گردند.

### س3: چطور فیلترها را پاک کنم؟
**ج**: دو روش:
1. کلیک روی دکمه "🔄 بازنشانی"
2. Refresh صفحه (F5)

### س4: چرا برخی مقالات فیلتر نمی‌شوند؟
**ج**: مقالاتی که اطلاعات کامل ندارند (مثل بدون سطح دشواری) ممکن است پنهان شوند. برای دیدن همه، روی "بازنشانی" کلیک کنید.

### س5: آیا می‌توانم چند سطح را انتخاب کنم؟
**ج**: بله! می‌توانید هر تعداد گزینه را در هر فیلتر انتخاب کنید.

## 🔧 میانبرهای صفحه کلید

| کلید | عملکرد |
|------|--------|
| `ESC` | بستن پنجره فیلتر |
| `Tab` | حرکت بین فیلترها |
| `Space` | انتخاب/لغو انتخاب checkbox |
| `Enter` | اعمال فیلتر (وقتی روی دکمه هستید) |

```
هدف: پیدا کردن مقالات کوتاه و ساده

تنظیمات:
✅ زمان: 0-10 دقیقه
✅ سطح: مبتدی
```

## 🎓 نکات پیشرفته

### 1. فیلتر دینامیک
هر بار که فیلتری را تغییر می‌دهید، تعداد نتایج به‌روز می‌شود:
```
"25 مقاله یافت شد" → تغییر فیلتر → "12 مقاله یافت شد"
```

### 2. انیمیشن‌ها
- مقالات با انیمیشن fade in/out نمایش/مخفی می‌شوند
- پنجره فیلتر با انیمیشن smooth باز/بسته می‌شود

### 3. Responsive
سیستم کاملاً responsive است و در همه سایزهای صفحه به خوبی کار می‌کند.
