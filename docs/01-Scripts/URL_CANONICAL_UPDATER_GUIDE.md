## 📖 توضیحات

این اسکریپت پایتون برای به‌روزرسانی خودکار URL و Canonical در front matter تمام مقالات Hugo طراحی شده است. این اسکریپت segment جدید `knowledge` را به URLهای موجود اضافه می‌کند.

### تغییراتی که اعمال می‌شود:

```
از:  https://davoodya.ir/cyber-security/...
به:  https://davoodya.ir/knowledge/cyber-security/...
```

---

## ✨ ویژگی‌ها

1. **پیمایش بازگشتی**: تمام فایل‌های Markdown در دایرکتوری و زیردایرکتوری‌ها را پردازش می‌کند

2. **پشتیبانی از فرمت‌های مختلف Front Matter**:
   - YAML (`---`)
   - TOML (`+++`)

3. **پشتیبانی از فرمت‌های مختلف تعریف property**:
   - `url = "..."`
   - `url: "..."`
   - `canonical = "..."`
   - `canonical: "..."`

4. **Handle کردن Space در مسیر**: مسیرهایی که شامل فاصله هستند به درستی پردازش می‌شوند

5. **دایرکتوری پیش‌فرض**: اگر مسیری وارد نشود، خودکار از `content/` استفاده می‌کند

6. **گزارش‌دهی کامل**:
   - لاگ دقیق در فایل
   - گزارش جزئیات فایل‌های پردازش شده
   - آمار کامل

7. **ایمنی**:
   - تایید کاربر قبل از شروع
   - بررسی وجود front matter
   - مدیریت خطاها

## 🚀 نحوه استفاده

### روش 1: استفاده با دایرکتوری پیش‌فرض (content/)

```bash
python url-canonical-updater.py
```

سپس Enter بزنید تا از دایرکتوری پیش‌فرض استفاده شود.

### روش 2: استفاده با مسیر دلخواه

```bash
python url-canonical-updater.py
```

سپس مسیر دایرکتوری را وارد کنید:
```
h:\Repo\Hugo\davoodya\content\cyber-security
```

### روش 3: مسیرهای با فاصله

اگر مسیر شامل فاصله است:
```
h:\Repo\Hugo\My Site\content
```

یا می‌توانید با کوتیشن وارد کنید:
```
"h:\Repo\Hugo\My Site\content"
```

## ⚠️ نکات مهم

### 1. پشتیبان‌گیری
**قبل از اجرای اسکریپت حتما از فایل‌های خود backup بگیرید!**

```bash
# با Git
git add .
git commit -m "Before URL update"

# یا کپی دستی
cp -r content content_backup
```

### 2. تست روی تعداد کمی فایل
قبل از اجرا روی همه فایل‌ها، روی یک دایرکتوری کوچک تست کنید:

```bash
python url-canonical-updater.py
# سپس مسیر: content/cyber-security/SANS-401
```

### 3. فایل‌هایی که پردازش نمی‌شوند
اسکریپت فایل‌های زیر را رد می‌کند:
- فایل‌های بدون front matter
- فایل‌هایی که URL قدیمی ندارند
- فایل‌هایی که قبلا به‌روزرسانی شده‌اند

### 4. بررسی نتایج
بعد از اجرا:
1. فایل لاگ را چک کنید
2. فایل گزارش را مطالعه کنید
3. چند فایل را به صورت دستی بررسی کنید
4. سایت Hugo را build کنید تا مطمئن شوید مشکلی وجود ندارد

```bash
hugo server
```

### 5. ساختار مسیرها
اسکریپت تنها URL داخل front matter را تغییر می‌دهد. ساختار فایل‌ها و دایرکتوری‌ها دست نخورده باقی می‌ماند.

### 6. اجرای مجدد
اگر اسکریپت را دوباره اجرا کنید:
- فایل‌های قبلا به‌روزرسانی شده رد می‌شوند
- تنها فایل‌های جدید یا باقی‌مانده پردازش می‌شوند

## 🔍 عیب‌یابی

### مشکل: "دایرکتوری وجود ندارد"
**راه حل**: مطمئن شوید مسیر را درست وارد کرده‌اید. از مسیر کامل (absolute path) استفاده کنید.

### مشکل: "هیچ فایل Markdown یافت نشد"
**راه حل**: 
- مطمئن شوید فایل‌های `.md` در دایرکتوری وجود دارند
- بررسی کنید پسوند فایل‌ها `.md` است

### مشکل: "front matter یافت نشد"
**راه حل**: 
- مطمئن شوید فایل دارای front matter است
- front matter باید با `---` یا `+++` شروع شود

### مشکل: فایل‌ها پردازش نمی‌شوند
**راه حل**:
- لاگ فایل را چک کنید
- مطمئن شوید URL قدیمی در front matter وجود دارد
- بررسی کنید فرمت front matter صحیح است
