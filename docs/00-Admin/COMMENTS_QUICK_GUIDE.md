# 💬 سیستم کامنت - راهنمای سریع

## 🚀 شروع سریع

### 1. فایل‌ها موجود است ✅

```
✓ api/comments.php          → API اصلی
✓ api/admin.php             → پنل مدیریت
✓ api/admin_save.php        → ذخیره تغییرات
✓ api/.htaccess             → تنظیمات
✓ data/user_comments.json   → ذخیره کامنت‌ها
✓ static/assets/js/comments.js  → فرانت‌اند
```

### 2. تنظیم مجوزها

```bash
chmod 666 data/user_comments.json
```

### 3. تست کنید

**صفحه مقاله:**
```
http://localhost:1313/article-name/
```

**پنل ادمین:**
```
http://localhost/api/admin.php
```

## 📝 نحوه استفاده

### کاربر عادی:
1. فرم را پر کند
2. "ارسال دیدگاه" کلیک کند
3. پیام: "پس از بررسی نمایش داده می‌شود"
4. کامنت در انتظار تایید

### ادمین:
1. با ایمیل ادمین فرم را پر کند
2. "ارسال دیدگاه" کلیک کند
3. کامنت **بلافاصله** نمایش داده می‌شود
4. `confirmed: true`

### تایید کامنت:
1. باز کنید: `/api/admin.php`
2. تب "در انتظار تایید"
3. "تایید" کلیک کنید
4. کامنت نمایش داده می‌شود

## 🎯 قوانین

### `confirmed: true` زمانی که:
- ایمیل = `davoodya40@gmail.com`
- یا ادمین در پنل تایید کرده باشد

### `confirmed: false` زمانی که:
- ایمیل ≠ ایمیل ادمین
- نیاز به تایید دارد

### نمایش داده می‌شود:
- فقط کامنت‌های `confirmed: true`
