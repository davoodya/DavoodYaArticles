# راهنمای سیستم فیلتر مقالات

## 📋 توضیحات

سیستم فیلتر مقالات به کاربران این امکان را می‌دهد که مقالات را بر اساس ویژگی‌های مختلف فیلتر کنند:

- **مدت زمان مطالعه**: از 0 تا 60 دقیقه (با استفاده از Range Slider)
- **سطح دشواری**: مبتدی، متوسط، حرفه‌ای، تخصصی
- **نیاز به تمرین عملی**: دارد یا ندارد
- **نوع پست**: آموزشی، مقاله، اسکریپت، خبر، دستور العمل، معرفی، ابزار

## 🎨 ویژگی‌های طراحی

### دسکتاپ (Desktop)
- فیلترها در sidebar در یک منوی Dropdown نمایش داده می‌شوند
- عنوان: "🔧 فیلتر بر اساس ویژگی"
- دکمه‌های اعمال و بازنشانی فیلترها
- نمایش تعداد مقالات یافت شده

### موبایل (Mobile)
- دکمه شناور "فیلتر" در کنار صفحه (پایین سمت چپ)
- با کلیک روی دکمه، یک صفحه کامل (Modal) باز می‌شود
- تمامی فیلترها در این صفحه نمایش داده می‌شوند
- بستن Modal با دکمه × یا کلید ESC

## 🔧 نحوه کار

### 1. تشخیص خودکار ویژگی‌های مقاله

سیستم به صورت خودکار Badge های موجود در Article Cards را می‌خواند و ویژگی‌های زیر را استخراج می‌کند:

```javascript
// نمونه data attributes که به مقالات اضافه می‌شود:
article.dataset.readingTime = 14;
article.dataset.difficulty = "intermediate";
article.dataset.labRequired = true;
article.dataset.postType = "آموزشی";
```

### 2. فیلتر کردن مقالات

وقتی کاربر فیلترها را تنظیم کرده و روی "اعمال فیلتر" کلیک می‌کند:

1. مقالاتی که با فیلترها مطابقت دارند نمایش داده می‌شوند
2. مقالاتی که مطابقت ندارند مخفی می‌شوند (با انیمیشن fadeOut)
3. تعداد مقالات یافت شده به‌روزرسانی می‌شود
4. در صورت نبود مقاله، پیام "هیچ مقاله‌ای یافت نشد" نمایش داده می‌شود

### 3. Range Slider برای مدت زمان

- دو slider: یکی برای حداقل و یکی برای حداکثر
- اختلاف حداقل بین دو slider: 5 دقیقه
- نمایش مقدار فعلی بالای slider ها

## 🎯 Front Matter Properties

برای اینکه فیلترها کار کنند، مقالات باید این Front Matter Properties را داشته باشند:

```toml
readingTime = 14                    # عدد صحیح (دقیقه)
difficulty = "intermediate"         # beginner | medium | intermediate | advanced
lab_required = true                 # true | false
post_type_fa = "آموزشی"            # آموزشی | مقاله | اسکریپت | خبر | دستور العمل | معرفی | ابزار
```

## 📱 Responsive Design

### دسکتاپ (> 1024px)
- فیلترها در sidebar
- Dropdown برای نمایش/مخفی کردن فیلترها
- دکمه شناور موبایل مخفی است

### موبایل/تبلت (≤ 1024px)
- Sidebar در پایین صفحه نمایش داده می‌شود
- دکمه شناور فیلتر نمایش داده می‌شود
- با کلیک روی دکمه، Modal تمام صفحه باز می‌شود

## 🔄 عملکرد خاص

### 1. مخفی کردن فیلترها در صفحات بدون مقاله

اگر در صفحه‌ای مقاله‌ای وجود نداشته باشد:
- فیلتر در sidebar مخفی می‌شود
- دکمه شناور موبایل مخفی می‌شود

### 2. پیام "هیچ مقاله‌ای یافت نشد"

وقتی هیچ مقاله‌ای با فیلترها مطابقت ندارد:
- یک پیام با آیکون 🔍 نمایش داده می‌شود
- متن: "هیچ مقاله‌ای یافت نشد - لطفاً فیلترهای خود را تغییر دهید یا بازنشانی کنید"

### 3. Scroll به بالای لیست

پس از اعمال فیلتر در دسکتاپ، صفحه به صورت smooth به بالای لیست مقالات scroll می‌شود.

## 🐛 Troubleshooting

### فیلترها کار نمی‌کنند

1. **بررسی کنید که فایل JavaScript لود شده باشد:**
   - باز کردن Developer Tools (F12)
   - رفتن به تب Console
   - بررسی خطاها

2. **بررسی Front Matter مقالات:**
   - مطمئن شوید که مقالات properties لازم را دارند
   - مقادیر باید دقیقاً مطابق فرمت باشند

3. **بررسی Badge های مقاله:**
   - Badge ها باید در Article Card نمایش داده شوند
   - کلاس‌های CSS باید صحیح باشند

### دکمه موبایل نمایش داده نمی‌شود

- بررسی کنید که عرض صفحه کمتر از 1024px باشد
- بررسی کنید که مقاله‌ای در صفحه وجود داشته باشد

## 📝 نمونه استفاده

### مثال 1: فیلتر مقالات مبتدی با مدت زمان کمتر از 20 دقیقه

1. باز کردن فیلترها
2. تنظیم Range Slider: 0 - 20 دقیقه
3. انتخاب فقط "مبتدی" در سطح دشواری
4. کلیک روی "اعمال فیلتر"

### مثال 2: فیلتر مقالات آموزشی که نیاز به تمرین عملی دارند

1. باز کردن فیلترها
2. در "نیاز به تمرین عملی"، فقط "دارد" را انتخاب کنید
3. در "نوع پست"، فقط "آموزشی" را انتخاب کنید
4. کلیک روی "اعمال فیلتر"

## 🎓 نکات مهم

1. **Performance**: فیلترها به صورت Client-side اجرا می‌شوند و نیازی به server request ندارند
2. **Accessibility**: تمامی المان‌ها دارای label و aria-label مناسب هستند
3. **Animation**: استفاده از انیمیشن‌های smooth برای بهبود UX
4. **Responsive**: عملکرد کامل در تمامی دیوایس‌ها
5. **RTL Support**: پشتیبانی کامل از راست به چپ
