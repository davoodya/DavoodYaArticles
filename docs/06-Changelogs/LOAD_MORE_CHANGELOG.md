# 📝 تغییرات سیستم بارگذاری بیشتر (Load More Changelog)

## نسخه 1.0.0 - 10 فوریه 2026

### 🎯 هدف اصلی
تبدیل سیستم pagination معمولی به سیستم "بارگذاری بیشتر" (Load More) با قابلیت فیلتر کردن تمام مقالات.

---

## ✨ ویژگی‌های جدید

### 1. سیستم بارگذاری بیشتر (Load More)
- بارگذاری تدریجی مقالات (4 تا 4)
- دکمه "بارگذاری بیشتر" با طراحی Cyberpunk
- نمایش تعداد مقالات باقی‌مانده
- انیمیشن fadeInUp برای مقالات جدید
- پنهان شدن خودکار دکمه پس از نمایش همه مقالات

### 2. فیلتر روی تمام مقالات
- فیلترها بر روی **تمام مقالات** دسته‌بندی اعمال می‌شوند
- نه فقط مقالات نمایش داده شده
- بهبود سرعت بارگذاری در مقایسه با بارگذاری همه مقالات یکجا

### 3. یکپارچگی با سیستم فیلتر
- API جدید برای فیلترها
- اولویت‌بندی سیستم‌های فیلتر
- Fallback به HTML برای مرورگرهای بدون JavaScript

## 🔄 مهاجرت از Pagination به Load More

### قبل:
```
صفحه 1: مقالات 1-4
صفحه 2: مقالات 5-8
صفحه 3: مقالات 9-12
...
```

**مشکلات**:
- فیلتر فقط روی مقالات صفحه فعلی
- برای فیلتر روی همه: باید همه مقالات در یک صفحه باشند
- سرعت پایین با تعداد زیاد مقالات

### بعد:
```
بارگذاری اول: مقالات 1-4
کلیک 1: مقالات 1-8
کلیک 2: مقالات 1-12
...
```

**مزایا**:
- فیلتر روی تمام مقالات (از JSON)
- بارگذاری سریع اولیه
- بارگذاری تدریجی بقیه مقالات
- مقیاس‌پذیر

## 🔍 نکات فنی

### 1. چرا JSON؟
- **دلیل**: برای دسترسی به تمام مقالات بدون بارگذاری در HTML
- **هزینه**: یک درخواست HTTP اضافی (~20-50KB)
- **مزیت**: فیلتر روی تمام مقالات

### 2. چرا تدریجی؟
- **دلیل**: بهبود سرعت بارگذاری اولیه
- **هزینه**: کمی پیچیدگی بیشتر در کد
- **مزیت**: تجربه کاربری بهتر

### 3. چرا Fallback به HTML?
- **دلیل**: سازگاری با مرورگرهای بدون JavaScript
- **هزینه**: HTML بزرگتر
- **مزیت**: SEO بهتر، دسترسی بیشتر
