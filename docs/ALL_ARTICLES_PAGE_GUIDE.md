# راهنمای صفحه "تمام مقالات"

## 📋 معرفی

صفحه **"تمام مقالات"** یک صفحه جامع است که تمام مقالات منتشر شده در وبسایت را در یک مکان نمایش می‌دهد. این صفحه به کاربران اجازه می‌دهد تا به راحتی تمام محتوای وبسایت را مرور کنند.

## ✨ ویژگی‌ها

### 1. نمایش تمام مقالات
- **تمام مقالات** از همه دسته‌بندی‌ها در یک صفحه نمایش داده می‌شوند
- مرتب‌سازی بر اساس **جدیدترین** مقالات
- نمایش **تصویر شاخص**، **خلاصه**، و **Badge های ویژگی** برای هر مقاله

### 2. آمار سایت
صفحه شامل دو آمار مهم است:
- **تعداد کل مقالات**: نمایش تعداد کل مقالات منتشر شده
- **تعداد دسته‌بندی‌ها**: نمایش تعداد دسته‌بندی‌های موجود

### 3. دسته‌بندی مقاله
- هر کارت مقاله شامل **لینک دسته‌بندی** آن مقاله است
- با کلیک روی دسته‌بندی، کاربر به صفحه آن دسته‌بندی هدایت می‌شود

### 4. Pagination
- برای بهبود عملکرد، مقالات در صفحات مختلف نمایش داده می‌شوند
- پیمایش آسان بین صفحات با دکمه‌های قبلی/بعدی

## 🔗 راه‌های دسترسی

کاربران از **دو راه مختلف** می‌توانند به صفحه "تمام مقالات" دسترسی داشته باشند:

### 1. دکمه در انتهای صفحه اصلی
در انتهای صفحه اصلی، پس از نمایش همه دسته‌بندی‌ها، یک دکمه برجسته وجود دارد:
```
📋 مشاهده تمام مطالب ←
```
این دکمه با اندازه مناسب طراحی شده تا UI صفحه را بهم نریزد.

### 2. دسته‌بندی در سایدبار
در سایدبار، در بخش "دسته‌بندی‌ها"، اولین آیتم **"تمام مقالات"** است که:
- با استایل خاص برجسته شده است
- تعداد کل مقالات را نمایش می‌دهد
- با border و background ویژه متمایز است

## 📁 ساختار فایل‌ها

### 1. محتوا
**مسیر**: `content/all-articles/_index.md`

```markdown
+++
title = "تمام مقالات"
description = "مشاهده تمام مقالات منتشر شده در سایت به صورت یکجا"
featured_image = "/images/general/gohugo-default-sample-hero-image.jpg"
layout = "all-articles"
+++

این صفحه تمام مقالات منتشر شده در وبسایت را نمایش می‌دهد.
```

⚠️ **نکته مهم**: این دایرکتوری را **هرگز پاک نکنید**! برای عملکرد صحیح صفحه "تمام مقالات" ضروری است. همچنین **هیچ مقاله‌ای را در این دایرکتوری قرار ندهید** - فقط فایل `_index.md` باید در اینجا باشد.

### 2. Template
**مسیر**: `layouts/_default/all-articles.html`

این template شامل:
- هدر صفحه با عنوان و توضیحات
- آمار سایت (تعداد مقالات و دسته‌بندی‌ها)
- Grid مقالات با کارت‌های کامل
- Pagination

### 3. صفحه اصلی
**مسیر**: `layouts/index.html`

تغییرات:
- اضافه شدن `view-all-articles-footer` با دکمه در انتهای صفحه

### 4. سایدبار
**مسیر**: `layouts/partials/sidebar.html`

تغییرات:
- اضافه شدن آیتم "تمام مقالات" در ابتدای لیست دسته‌بندی‌ها
- استایل خاص برای این آیتم
- نمایش تعداد کل مقالات با `{{ len site.RegularPages }}`

هر کارت مقاله در صفحه "تمام مقالات" شامل Badge های زیر است:

1. **مدت زمان مطالعه** (readingTime)
2. **سطح دشواری** (difficulty)

4. **نوع پست** (post_type_fa)

این Badge ها به کاربران کمک می‌کنند تا سریع‌تر مقالات مناسب را پیدا کنند.

## 🔧 تنظیمات

### تغییر تعداد مقالات در هر صفحه

برای تغییر تعداد مقالات نمایش داده شده در هر صفحه، می‌توانید در فایل `hugo.toml` پارامتر `paginate` را تغییر دهید:

```toml
paginate = 12  # تعداد مقالات در هر صفحه (پیش‌فرض Hugo)
```

### تغییر مرتب‌سازی مقالات

در حال حاضر، مقالات بر اساس تاریخ (جدیدترین اول) مرتب می‌شوند. برای تغییر مرتب‌سازی، خط زیر را در `all-articles.html` ویرایش کنید:

```go
{{ $allPages = $allPages.ByDate.Reverse }}
```

گزینه‌های دیگر:
- `.ByTitle`: مرتب‌سازی بر اساس عنوان
- `.ByPublishDate`: مرتب‌سازی بر اساس تاریخ انتشار
- `.ByLastmod`: مرتب‌سازی بر اساس آخرین بروزرسانی

### تنظیم اندازه دکمه

اندازه دکمه "مشاهده تمام مطالب" در فایل CSS قابل تنظیم است:

```css
.view-all-btn {
    padding: 0.9rem 1.8rem;  /* اندازه دسکتاپ */
    font-size: 1rem;
}

@media (max-width: 768px) {
    .view-all-btn {
        padding: 0.8rem 1.5rem;  /* اندازه موبایل */
        font-size: 0.95rem;
    }
}
```

## ⚠️ مشکلات رایج و راه‌حل‌ها

### مشکل 1: تعداد مقالات اشتباه نمایش داده می‌شود

**علت**: دایرکتوری `all-articles` پاک شده یا مقالاتی در آن قرار گرفته است.

**راه‌حل**:
1. مطمئن شوید دایرکتوری `content/all-articles/` وجود دارد
2. فقط فایل `_index.md` در آن باشد
3. هیچ فایل مقاله‌ای در این دایرکتوری نباشد
4. فیلتر در template فعال است:
   ```go
   {{ $allPages := where site.RegularPages "Section" "!=" "all-articles" }}
   ```

### مشکل 2: صفحه "تمام مقالات" خطای 404 می‌دهد

**علت**: دایرکتوری `all-articles` حذف شده است.

**راه‌حل**:
```bash
# ایجاد دایرکتوری
mkdir content/all-articles

# ایجاد فایل _index.md
# محتوا را از بالا کپی کنید
```

### مشکل 3: مقالات تکراری نمایش داده می‌شوند

**علت**: مقالاتی در دایرکتوری `all-articles` قرار داده شده‌اند.

**راه‌حل**:
1. تمام فایل‌های `.md` به جز `_index.md` و `README.md` را حذف کنید
2. مقالات را به دایرکتوری‌های دسته‌بندی مناسب منتقل کنید

### مشکل 4: تعداد در سایدبار صفر است

**علت**: فیلتر صحیح در sidebar اعمال نشده است.

**راه‌حل**:
مطمئن شوید در `sidebar.html` کد زیر وجود دارد:
```go
{{ $realArticles := where site.RegularPages "Section" "!=" "all-articles" }}
{{ $realArticles = where $realArticles "Draft" false }}
<span class="category-badge">{{ len $realArticles }}</span>
```
