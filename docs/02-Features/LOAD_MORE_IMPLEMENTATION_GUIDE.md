# 📚 راهنمای پیاده‌سازی سیستم بارگذاری بیشتر (Load More)

## 📋 خلاصه تغییرات

تاریخ: 10 فوریه 2026

### 🎯 هدف
تغییر سیستم صفحه‌بندی از pagination معمولی به سیستم "بارگذاری بیشتر" (Load More) با قابلیت فیلتر کردن تمام مقالات یک دسته‌بندی.

---

## 🚀 ویژگی‌های جدید

### 1. بارگذاری تدریجی مقالات
- **تعداد اولیه**: 4 مقاله در بارگذاری اول صفحه
- **افزایش**: 4 مقاله با هر کلیک روی دکمه "بارگذاری بیشتر"
- **ادامه**: تا زمان نمایش تمام مقالات دسته‌بندی

### 2. فیلتر روی تمام مقالات
- فیلترها روی **تمام مقالات** دسته‌بندی اعمال می‌شوند (نه فقط مقالات نمایش داده شده)
- پس از اعمال فیلتر، مقالات از ابتدا نمایش داده می‌شوند
- سرعت بارگذاری صفحه بهبود یافته (در مقایسه با بارگذاری همه مقالات یکجا)

### 3. انیمیشن و تجربه کاربری
- انیمیشن fadeInUp برای مقالات جدید
- دکمه بارگذاری بیشتر با طراحی Cyberpunk
- نمایش تعداد مقالات باقی‌مانده
- پنهان شدن خودکار دکمه پس از نمایش همه مقالات

## 📁 فایل‌های تغییر یافته

### 1. `static/assets/js/load-more.js` (جدید ✨)
**مسئولیت**: مدیریت سیستم بارگذاری بیشتر

```javascript
// ویژگی‌های کلیدی:
- بارگذاری مقالات از JSON
- نمایش تدریجی مقالات (4 تا 4)
- ایجاد دکمه بارگذاری بیشتر
- API برای فیلترها:
  * window.applyLoadMoreFilter()
  * window.resetLoadMoreFilter()
  * window.getTotalArticlesCount()
```

**تنظیمات قابل تغییر**:
```javascript
const ARTICLES_PER_LOAD = 4; // تعداد مقالات در هر بار بارگذاری
```

---

### 2. `static/assets/js/filters.js` (به‌روزرسانی 🔄)
**تغییرات**:
- افزودن پشتیبانی از API سیستم Load More
- اولویت‌بندی سیستم‌های فیلتر:
  1. Load More (اولویت اول)
  2. Articles Loader (قدیمی)
  3. DOM-based filtering (fallback)

```javascript
// در تابع applyFilters:
if (typeof window.applyLoadMoreFilter === 'function') {
    // استفاده از Load More
} else if (typeof window.applyArticlesFilter === 'function') {
    // استفاده از Articles Loader
} else {
    // Fallback
}
```

## 🔄 نحوه کار سیستم

### مرحله 1: بارگذاری صفحه
```
1. کاربر وارد صفحه دسته‌بندی می‌شود
2. Hugo فایل list.html را رندر می‌کند
3. JavaScript فایل index.json را fetch می‌کند
4. تمام مقالات در حافظه (memory) ذخیره می‌شوند
5. فقط 4 مقاله اول نمایش داده می‌شود
6. دکمه "بارگذاری بیشتر" ظاهر می‌شود
```

### مرحله 2: کلیک بارگذاری بیشتر
```
1. کاربر روی دکمه کلیک می‌کند
2. 4 مقاله بعدی از حافظه خوانده می‌شود
3. با انیمیشن fadeInUp نمایش داده می‌شوند
4. شمارنده مقالات باقی‌مانده به‌روز می‌شود
5. اگر مقاله‌ای نماند، دکمه مخفی می‌شود
```

### مرحله 3: اعمال فیلتر
```
1. کاربر فیلتری را فعال می‌کند
2. تابع applyLoadMoreFilter فراخوانی می‌شود
3. تمام مقالات در حافظه فیلتر می‌شوند
4. مقالات فعلی پاک می‌شوند
5. از ابتدا 4 مقاله اول (فیلتر شده) نمایش داده می‌شود
6. دکمه بارگذاری بیشتر برای مقالات فیلتر شده فعال می‌شود
```

## 📊 مزایا و معایب

### ✅ مزایا

1. **بهبود سرعت بارگذاری**
   - فقط 4 مقاله در بارگذاری اول
   - کاهش حجم HTML اولیه

2. **فیلتر روی تمام مقالات**
   - بدون نیاز به بارگذاری همه مقالات در HTML
   - کاربر می‌تواند تمام مقالات را فیلتر کند

3. **تجربه کاربری بهتر**
   - انیمیشن‌های روان
   - بارگذاری تدریجی (Progressive Loading)
   - بدون Reload صفحه

4. **مقیاس‌پذیری**
   - با افزایش تعداد مقالات مشکلی ایجاد نمی‌شود
   - فقط مقالات مورد نیاز در DOM هستند

### ⚠️ معایب (و راه‌حل‌ها)

1. **وابستگی به JavaScript**
   - **راه‌حل**: در صورت غیرفعال بودن JS، همه مقالات در HTML موجودند

2. **یک درخواست HTTP اضافی (JSON)**
   - **تاثیر**: ناچیز (فایل JSON فشرده است)
   - **مزیت**: فیلتر بر روی تمام مقالات

3. **عدم پشتیبانی مرورگرهای قدیمی**
   - **راه‌حل**: سیستم fallback به HTML موجود

## 🐛 عیب‌یابی (Troubleshooting)

### مشکل 1: دکمه بارگذاری بیشتر ظاهر نمی‌شود
**بررسی**:
1. آیا فایل JSON در مسیر صحیح است؟
2. Console چه خطایی می‌دهد؟
3. آیا اسکریپت load-more.js لود شده؟

**راه‌حل**:
```bash
# تست JSON:
curl https://your-site.com/category-name/index.json
```

### مشکل 2: فیلترها کار نمی‌کنند
**بررسی**:
1. آیا `window.applyLoadMoreFilter` تعریف شده است؟
2. Console چه خطایی می‌دهد؟

**راه‌حل**:
```javascript
// در Console:
console.log(typeof window.applyLoadMoreFilter); // باید 'function' برگرداند
```

### مشکل 3: تصاویر نمایش داده نمی‌شوند
**بررسی**:
1. URL تصاویر در JSON صحیح است؟
2. آیا از relURL استفاده شده؟

**راه‌حل**:
```go
// در list.json:
{{- $featuredImage = .Params.featured_image | relURL -}}
```

### مشکل 4: انیمیشن کار نمی‌کند
**بررسی**:
1. آیا CSS لود شده؟
2. آیا @keyframes تعریف شده؟

**راه‌حل**:
```css
/* اضافه کردن به main.css */
@keyframes fadeInUp { ... }
```
