# راهنمای TOC با دکمه شناور (Mobile & Desktop)

## 📋 خلاصه

سیستم TOC حالا در **همه دیوایس‌ها** (Desktop, Tablet, Mobile) از **دکمه شناور** استفاده می‌کند.

---

## ✨ تغییرات جدید

### ❌ حذف شده:
- دکمه "نمایش/مخفی کردن فهرست" در موبایل

### ✅ اضافه شده:
- دکمه شناور در موبایل (مثل Desktop)
- Responsive sizes برای دکمه در سایزهای مختلف
- بهبود تجربه کاربری در موبایل

## 🎨 استایل‌های کلیدی

### دکمه در موبایل:

```css
@media (max-width: 768px) {
    .toc-floating-btn {
        display: flex !important;  /* نمایش همیشگی */
        width: 50px;
        height: 50px;
        left: 10px;
        top: 50%;
        transform: translateY(-50%);
    }
}
```

### سایدبار در موبایل:

```css
@media (max-width: 768px) {
    .toc-floating-sidebar {
        width: 90%;
        max-width: 350px;
        left: -100%;
    }
    
    .toc-floating-sidebar.active {
        left: 0;
    }
}
```

### حذف دکمه Toggle:

```css
.toc-toggle {
    display: none !important;  /* حذف کامل */
}
```

## 🔄 تغییرات اعمال شده

### 1. فایل `toc.css`:

**اضافه شده:**
- دکمه شناور در موبایل
- سایزهای Responsive برای دکمه
- بهینه‌سازی برای لمس (touch)

### 2. فایل `single.html`:

**حذف شده:**
```html
<!-- این دیگر وجود ندارد -->
<button class="toc-toggle" onclick="toggleTOC()">
    نمایش/مخفی کردن فهرست
</button>
```

**اضافه شده:**
- aria-label برای accessibility
- Event listeners بیشتر
- Prevent body scroll در موبایل
- Handle orientation change

## 📝 کد CSS کامل برای موبایل

```css
/* موبایل - 768px تا 480px */
@media (max-width: 768px) {
    .toc-floating-btn {
        display: flex !important;
        width: 50px;
        height: 50px;
        left: 10px;
    }
    
    .toc-floating-btn svg {
        width: 24px;
        height: 24px;
    }
    
    .toc-floating-sidebar {
        width: 90%;
        max-width: 350px;
    }
}

/* موبایل کوچک - زیر 480px */
@media (max-width: 480px) {
    .toc-floating-btn {
        width: 45px;
        height: 45px;
        left: 8px;
    }
    
    .toc-floating-btn svg {
        width: 22px;
        height: 22px;
    }
    
    .toc-floating-sidebar {
        width: 95%;
        max-width: 100%;
    }
}

/* Landscape موبایل */
@media (max-width: 768px) and (orientation: landscape) {
    .toc-floating-btn {
        top: auto;
        bottom: 20px;
        transform: none;
    }
}
```

## 💡 بهبودهای تجربه کاربری

### 1. Touch Friendly:
- سایز دکمه بزرگ برای لمس راحت
- فاصله مناسب از لبه

### 2. Performance:
- Hardware acceleration (transform)
- Smooth animations (cubic-bezier)
- No reflows

### 3. Accessibility:
- aria-label برای screen readers
- Focus management
- Keyboard support (ESC)

### 4. UX:
- Visual feedback (pulse animation)
- Badge تعداد headings
- Automatic close بعد از کلیک
- Prevent body scroll
