Each Page of Links to Your Site

  1. Who Links the Most => More
    1. هنگامیکه بر روی More کلیک میکنیم و تمامی داده ها نمایش داده میشود میتوانیم تعداد Backlinks و صفحه ای که Backlinks شده را نیز مشاهده کنیم.
    2. مثلا در تصویر زیر مشاهده میکنیم که وبسایت https://barnamenevisan.org تعداد 1106762 بک لینک به 171 صفحه Top Learn داشته است:
      1. ![[Pasted image 20260124173013.png]]
  2. You Most Linked Content => More
    1. در این صفحه نیز تمام صفحات از وبسایت ما Backlink آنها توسط سایر وبسایت ها استفاده شده است را مشاهده میکنیم.
    2. مثلا صفحه اصلی تاپ لرن https://toplearn.com/ به تعداد 278366 بار توسط 62 دامنه متفاوت Backlinks شده است:
      1. ![[Pasted image 20260124173518.png]]
  3. How Your data is Linked => More
    1. در این صفحه نیز مشاهده میکنیم که Backlinks هایی که به وبسایت ما داده شده است با چه عناوینی پیاده سازی شده اند:
      1. ![[Pasted image 20260124173723.png]]
    2. ان کلمات کلیدی بسیار مهم هستند زیرا که توسط وبسایت های دیگر استفاده شده اند و مورد توجه کاربران قرار گرفته است.

  • مثلا در وبسایت https://barnamenevisan.org در سایدبار آن، لینک Top Learn همیشه و در تمام صفحات قرار دارد:

    • ![[Pasted image 20260124172519.png]]
  • نکته تکراری اما مهم: هر چه تعداد Backlinks های ما بیشتر باشد و از منابع معتبر تر باشد باعث افزایش رتبه بندی سئو ما میشود.

4. Search Traffic => International Targeting

4.1: Language Tab

اگر که وبسایت ما چند زبانه Multi Languages باشد باید در تمام صفحات از تگ hreflang استفاده کنیم که در این تگ مشخص میکنیم چه صفحه ای به چه منطقه یا زبانی نشان داده شود: ![[Pasted image 20260124175043.png]]

  • مثلا صفحه اصلی index-fa.html به فارسی زبانان ، و صفحه index-fr.html به فرانسوی زبانان نشان داده شود.
  • hreflang Tag
Show website for English language in USA
<link rel="alternate" href="https://example.com" hreflang="en-us">

Show website for Farsi language in Iran
<link rel="alternate" href="https://example.com" hreflang="fa-ir">

Show website for Española language in Spain 
<link rel="alternate" href="https://example.com" hreflang="es-es">

Show website for Española language in Mexico
<link rel="alternate" href="https://example.com" hreflang="es-mx">

Show website for French language in France
<link rel="alternate" href="https://example.com" hreflang="fr-fr">
  • نکته: در صورت داشتن وبسایت چند زبانه این تگ را باید برای تمام صفحات تعریف کنیم. در متد جدید حتی اگر وبسایت تک زبانه هم هست پیشنهاد میشود که برای افزایش رتبه بندی سئو از این تگ استفاده کنیم.
  • نکته دوم: برای تعریف hreflang میتوانیم بدون مشخص کردن منطقه هم از آن استفاده کنیم:
Show website for All English languages Countries
<link rel="alternate" href="https://example.com" hreflang="en">

Show website for All Farsi languages Countries
<link rel="alternate" href="https://example.com" hreflang="fa">

Show website for All Española languages Countries
<link rel="alternate" href="https://example.com" hreflang="es">

Show website for All French languages Countries
<link rel="alternate" href="https://example.com" hreflang="fr">

4.2: Country Tab

در این تب هم میتوانیم کشور و زبان کاربران هدف وبسایت خودمان را مشخص کنیم: ![[Pasted image 20260124175512.png]]

  • نکته: البته پیشنهاد میشود که این گزینه را فعال نکنیم زیرا که وبسایت اصولا کاربران ایرانی زبانی دارد که در خارج از ایران قرار دارند و در نتیجه با اینکار باعث میشویم که وبسایت برای آنها بدرستی نمایش داده نشود.
