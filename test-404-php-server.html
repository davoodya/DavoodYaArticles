🔧 تست صفحه 404 با PHP Server

راهنمای تست و اجرای صحیح سرور PHP با Router

❌ مشکل و ✅ راه‌حل

❌ مشکل قبلی

با اجرای دستور زیر، صفحه 404 شخصی‌سازی شده نمایش داده نمی‌شد:

cd public php -S localhost:8080 -t .
404 پیش‌فرض PHP

✅ راه‌حل جدید

با استفاده از Router Script، صفحه 404 شخصی نمایش داده می‌شود:

cd public php -S localhost:8080 router.php
404 شخصی‌سازی شده

🐛 رفع مشکلات

مشکل: Router.php یافت نشد

Error: No such file or directory

راه‌حل:

hugo --cleanDestinationDir cd public php -S localhost:8080 router.php

مشکل: صفحه 404 شخصی نمایش داده نمی‌شود

هنوز صفحه 404 پیش‌فرض PHP نمایش داده می‌شود

راه‌حل:

  1. مطمئن شوید از router.php استفاده می‌کنید (نه -t .)
  2. بررسی کنید که public/404.html وجود دارد
  3. Hard refresh: Ctrl+Shift+R
  4. سرور را restart کنید

مشکل: CSS/JS بارگذاری نمی‌شود

صفحه بدون استایل نمایش داده می‌شود

راه‌حل:

  1. F12 → Network Tab → بررسی فایل‌های قرمز (404)
  2. بررسی مسیرهای فایل در کد HTML
  3. Hugo را rebuild کنید
  4. مطمئن شوید Router MIME types صحیح را برمی‌گرداند

📚 مستندات

برای اطلاعات بیشتر، فایل‌های زیر را مطالعه کنید:

📄 404_PHP_SERVER_FIX.md - راهنمای کامل 📄 static/router.php - کد Router 📄 layouts/404.html - صفحه 404 📄 start-server.bat - Batch File
