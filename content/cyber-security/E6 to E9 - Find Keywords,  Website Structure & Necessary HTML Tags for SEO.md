### HTML Tags for SEO
#### Basic & Concepts
موتور جستجو از روی کدهای HTML است که میتواند بر روی محتویات وبسایت crawl کند در نتیجه برای افزایش رتبه وبسایت در سئو باید نکته های را در هنگام نوشتن کد های HTML وبسایت را رعایت کنیم. 
- مثلا برای افزایش رتبه سئو وبسایت باید تگ های زیر را در HTML خود داشته باشد.
#### Necessary HTML Tags for SEO
##### HTML Tags
- هر صفحه وبسایت ما باید تگهای زیر را به همراه پارامتر هایی که نوشتیم را در کدهای HTML خود داشته باشد:
```html
<html lang="en">
<head>
	<meta charset="UTF-8">
	<meta name="viewport" content="width=device-width, initial-scale=1.0">
	<meta http-equiv="X-UA-Compatib1e" content="ie=edge"> J
<tit1e>Document</tit1e>
</head>
<body>

</body>
</html>
```
	![[Pasted image 20240622233917.png]]
##### Tags Description
1. `<html lang="en">`
	1. تگ اصلی که قلمرو صفحه html هم محسوب میشود را باید با پارامتر Lang که مشخص کننده زبان صفحه است در کدهای صفحه قرار دهیم.
2. `<head>`
	1. در این تگ مشخصات و تنظیمات صفحه و همچنین References ها قرار میگیرد.	
3. `<meta name="" content="">`
	1. یکی از تگهای مهم در بحث سئو میباشد که ویژگی های متادیتا وبسایت در آن قرار میگرد. 
	2. `<meta name="Description" content="">`
		1. در این تگ توضیحات صفحه را مینویسیم که این توضیحات توسط گوگل ایندکس میشوند.
		2. در واقع تگ meta description شرحی از صفحه است که نباید از 160 کارکتر بیشتر باشد. فاصله های خالی هم جز کاراکتر ها محسوب میشوند.
		3. استفاده از تگ meta description هم واجب است.
		4. مثلا در تصویر زیر یک شرح مناسب برای عنوان آموزش برنامه نویسی در نظر گرفته ایم:
			1. ![[Pasted image 20240622235442.png]]
	3. `<meta name="Keywords" content="">`
		1. در تگ meta keywords هم کلمات کلیدی وبسایت را قرار میدهیم. کلمات کلیدی میتوانند از کلمات چند بخشی تشکیل شوند.
			1. ![[Pasted image 20240622235712.png]]
		2. هر کلمه کلیدی با استفاده از کاما `,` از هم جدا میشوند. 
		3. این تگ منسوخ شده محسوب میشود اما استفاده از آن هم ضرری ندارد.
4. `<title>`
	1. در این تگ تایتل و عنوان صفحه را مشخص میکنیم.
	2. این تگ هم در رتبه بندی وبسایت بسیار مهم است و استفاده از آن واجب است.
	3. عنوان صفحات باید با یکدیگر متفاوت باشند و در واقع دو صفحه نباید عنوان یکسان داشته باشند.
	4. هر عنوان حداکثر 65 کاراکتر میتواند داشته باشد و حداقل هم باید 3 بخش باشد مثلا *آموزش برنامه نویسی* و یا *آموزش سی شارپ* هر دو سه بخش و کمتر از 65 کاراکتر هستند و بسیار برای هنوان صفحه مناسب میباشند.
	5. در واقع موتور جستجو محتویات این تگ هر صفحه را ایندکس میکند و در نتایج جستجو عنوان صفحات را نشان میدهد.
		1. ![[Pasted image 20240622234913.png]]
		2. ![[Pasted image 20240622234916.png]]
5. `<body>`
	1. در این تگ هم محتویاتی که کاربر مشاهده میکند را قرار میدهیم. اگر این تگ در صفحه وجود نداشته باشد صفحه در جستجو های گوگل ایندکس نمیشود.
	2. `<H1>`
		1. در بدنه صفحه باید یک عدد تگ `<H1>` داشته باشیم و در این تگ عنوان متن و یا صفحه را وارد کنیم.
		2. نکته اینجاست که از این تگ یک عدد بیشتر نباید استفاده کرد.
	3. `<H2>, <H3>, ..., <H6>`
		1. سایر عنوان های وبسایت را نیز درون این تگها به ترتیب اوویت وارد میکنیم. استفاده از این تگها هم برای افزایش رتبه بندی سئو وبسایت پیشنهاد میشود.

#### SEO Friendly Link Defines 🔗
##### Basic & Concepts
بصورت پیشفرض هنگامیکه میخواهیم لینک دهی را در صفحه html انجام دهیم باید از تگ `<a href>` استفاده کنیم:
```html
<a href="https://toplearn.com/برنامه-نویسی-پیشرفته-یس-شارپ-از-صفر-تا-صد">
 آموزش سی شارپ 
 </a>
```
- در تصویر بالا مشاهده میکنیم در Hover  این Link عنوان صفحه مورد نظر که با کلیک بر روی آن به منتقل میشویم را میتوانیم مشاهده کنیم. حال اگر بخواهیم SEO را در لینک دهی رعایت کنیم باید *عنوان لینک* را در متن لینک بنویسیم. در واقع باید لینک دهی را به شکل زیر انجام دهیم:
```html
<a href="https://toplearn.com/برنامه-نویسی-پیشرفته-یس-شارپ-از-صفر-تا-صد">
 آموزش برنامه نویسی سی شارپ 
</a>
```

##### Define Link in HTML 
حال که هم URL به همراه عنوان و هم URL کوتاه شده داریم، اگر میخواهیم در صفحه HTML از لینکی را تعریف کنیم و یا میخواهیم لینک های تعریف شده را برای سئو بهینه کنیم، باید تعریف لینک را با URL کوتاه انجام دهیم تا به بهترین شکل توسط گوگل ایندکس شود.
- بنابراین اگر بخواهیم لینک دهی مثال بالا را انجام دهیم، ابتدا URL کوتاه شده، URL عنوان دار را بدست میاوریم و سپس >>
```html
<a href="https://toplearn.com/c/gyJ"> آموزش سی شارپ </a>
```

> بنابراین بهترین روش لینک دهی برای بهینه بودن سئو استفاده از URL کوتاه شده URL عنوان دار صفحه مورد نظر است.

##### Title in `<a title="">`
استفاده از فلگ title در تگ `<a>` هم میتواند باعث افزایش رتبه بندی سئو وبسایت شود. در واقع در صفحه UI وبسایت در هنگام Link Hover نیز میتوانیم این title را مشاهده کنیم. 
> اما استفاده از این title در افزایش رتبه سئو تاثییر بسرایی دارد زیرا موتور گوگل ابتدا محتویان این تگ را به عنوان تایتل صفحه میشناسد و اگر این تگ خالی باشد به سراغ متن بین تگ میرود در نتیجه استفاده از این فلگ میتواند تاثییر بسزایی در افزایش rating و سرع ایندکس شدن توسط گوگل وبسایت داشته باشد.

#### SEO Friendly Images
##### Images Functionality in Search Engines
نحوه لود شدن یک تصویر در گوگل >>
1. خود تصویر یکبار توسط گوگل ایندکس میشود.
2. متن درون alt تصویر هم یک بار بصورت مجزا ایندکس میشود.
> در نتیجه برای بهینه بودن سئو تصویر در گوگل، باید در تگ `<img>` دو فلگ `<alt title>` را حتما مقدار دهی کنیم. 
##### Advantage & Disadvantages of alt flag 
1. در واقع اگر تصویر لود نشود گوگل متن درون Alt را لود میکند. 
2. در مرورگر نابینایان فقط متن درون alt تصویر لود میشود و اگر تصویری متن alt نداشته باشد، صفحه ای که تصویر در آن قرار دارد امتیاز منفی در SEO دریافت میکند.
3. مرورگر ها قابلیتی بنام Dont load images دارند که اگر فعال باشد فقط Alt تصاویر لود میشود. در نتیجه اگر تصویری alt نداشته باشد در این مود از مرورگر هم نمیتواند لود شود و امتیاز منفی در SEO محسوب میشود.
##### Example of SEO Friendly Image

<img href="./images/files/1.jpg" alt="آموزش برنامه نویسی سی شارپ" title=""></img>
