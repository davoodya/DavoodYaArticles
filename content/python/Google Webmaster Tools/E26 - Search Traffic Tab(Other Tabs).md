### 4. Search Traffic => International Targeting
#### 4.1: Language Tab
اگر که وبسایت ما چند زبانه Multi Languages باشد باید در تمام صفحات از تگ `hreflang` استفاده کنیم که در این تگ مشخص میکنیم چه صفحه ای به چه منطقه یا زبانی نشان داده شود:
	![[Pasted image 20260124175043.png]]
- مثلا صفحه اصلی `index-fa.html` به فارسی زبانان ، و صفحه `index-fr.html` به فرانسوی زبانان نشان داده شود.
- `hreflang` Tag
```html
Show website for English language in USA
<link rel="alternate" href="https://example.com" hreflang="en-us">

Show website for Farsi language in Iran
<link rel="alternate" href="https://example.com" hreflang="fa-ir">

Show website for Española language in Spain 
<link rel="alternate" href="https://example.com" hreflang="es-es">

Show website for Española language in Mexico
<link rel="alternate" href="https://example.com" hreflang="es-mx">

Show website for French language in France
<link rel="alternate" href="https://example.com" hreflang="fr-fr">
```
- *نکته:* در صورت داشتن وبسایت چند زبانه این تگ را باید برای تمام صفحات تعریف کنیم. در متد جدید حتی اگر وبسایت تک زبانه هم هست پیشنهاد میشود که برای افزایش رتبه بندی سئو از این تگ استفاده کنیم.
- *نکته دوم:* برای تعریف `hreflang` میتوانیم بدون مشخص کردن منطقه هم از آن استفاده کنیم:
```html
Show website for All English languages Countries
<link rel="alternate" href="https://example.com" hreflang="en">

Show website for All Farsi languages Countries
<link rel="alternate" href="https://example.com" hreflang="fa">

Show website for All Española languages Countries
<link rel="alternate" href="https://example.com" hreflang="es">

Show website for All French languages Countries
<link rel="alternate" href="https://example.com" hreflang="fr">
```
