# ⚠️ هشدار مهم

## این دایرکتوری را پاک نکنید!

این دایرکتوری (`/content/all-articles/`) برای عملکرد صحیح صفحه **"تمام مقالات"** ضروری است.

### چرا این دایرکتوری مهم است؟

1. **ایجاد Section**: Hugo برای ایجاد صفحه "تمام مقالات" به این دایرکتوری نیاز دارد
2. **URL Routing**: این دایرکتوری URL `/all-articles/` را ایجاد می‌کند
3. **Template Rendering**: فایل `_index.md` مشخص می‌کند که از کدام template استفاده شود

### ساختار صحیح:

```
content/all-articles/
├── _index.md      # فایل اصلی برای تعریف صفحه
├── README.md      # این فایل (راهنما)
└── .gitkeep       # برای حفظ دایرکتوری در Git
```

### ⛔ نکات مهم:

- **هیچ فایل مقاله‌ای را در این دایرکتوری قرار ندهید**
- **فقط فایل `_index.md` باید در اینجا باشد**
- **مقالات باید در دایرکتوری‌های دسته‌بندی خودشان باشند** (مثلا `network/`, `linux/`, و غیره)

### اگر این دایرکتوری را پاک کنید:

❌ صفحه "تمام مقالات" کار نخواهد کرد  
❌ لینک‌های `/all-articles/` خطای 404 می‌دهند  
❌ دکمه "مشاهده تمام مطالب" به جایی هدایت نمی‌شود  
❌ آیتم سایدبار "تمام مقالات" کار نمی‌کند

### چگونه از نمایش تکراری مقالات جلوگیری می‌شود؟

در template `all-articles.html` از فیلتر زیر استفاده شده:

```go
{{ $allPages := where site.RegularPages "Section" "!=" "all-articles" }}
```

این فیلتر مطمئن می‌شود که هیچ محتوایی از خود دایرکتوری `all-articles` در لیست نمایش داده نشود.
