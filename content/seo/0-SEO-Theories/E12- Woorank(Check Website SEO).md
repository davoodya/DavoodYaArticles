### Woorank Tool
#### Description
ابزار [Woorank](https://woorank.com) یکی از ابزار های بررسی سئو وبسایت است. از ابزار Woorank بصورت رایگان یکبار در روز میتوان استفاده کرد. برای استفاده هم کافیست که URL وبسایت را وارد کنیم و سپس نتایج بررسی را مشاهده کنیم:
	![[Pasted image 20260120173303.png]]
- **نکته:** بطور کلی به ابزار ها زیاد نمیتوان اعتماد کرد اما برای بررسی ها میتوان از آنها استفاده کرد.
#### Tool Usage
برای دسترسی به ابزار Woorank میتوانیم از وبسایت [Woorank](https://woorank.com) و همچنین افزونه Chrome, Firefox استفاده کنیم.
