📋 راهنمای تست

این صفحه برای تست سریع سیستم Load More طراحی شده است.

مراحل تست:

  1. سرور Hugo را اجرا کنید: hugo server
  2. به آدرس دسته‌بندی بروید: http://localhost:1313/cyber-security/
  3. Console مرورگر را باز کنید (F12)
  4. تست‌های زیر را انجام دهید
