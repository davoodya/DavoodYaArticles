🔧 اصلاح موقعیت دکمه بستن Pop-up

مقایسه قبل و بعد

❌ قبل از اصلاح (اشتباه)

دکمه بستن در سمت راست

پیشنهاد مطالعه

⚠️ دکمه بستن با عنوان همپوشانی دارد

مشکل:
  • دکمه × در سمت راست قرار دارد
  • با عنوان "پیشنهاد مطالعه" همپوشانی می‌کند
  • در زبان فارسی نامناسب است
✅ بعد از اصلاح (صحیح)

دکمه بستن در سمت چپ

پیشنهاد مطالعه

✅ دکمه بستن در جایگاه صحیح قرار دارد

حل شد:
  • دکمه × در سمت چپ قرار گرفت
  • هیچ همپوشانی وجود ندارد
  • مناسب برای زبان فارسی (RTL)
  • z-index اضافه شد برای اطمینان

📝 تغییرات CSS

❌ قبل:

.suggestion-close {
  position: absolute;
  top: 1rem;
  right: 1rem;  /* ❌ اشتباه */
  width: 32px;
  height: 32px;
  ...
}

✅ بعد:

.suggestion-close {
  position: absolute;
  top: 1rem;
  left: 1rem;   /* ✅ صحیح */
  width: 32px;
  height: 32px;
  z-index: 10;  /* ✅ اضافه شد */
  ...
}

✅ خلاصه اصلاحات

1. تغییر موقعیت افقی:

از right: 1rem به left: 1rem

2. اضافه کردن z-index:

z-index: 10 برای اطمینان از نمایش روی سایر المان‌ها

3. اصلاح در Responsive breakpoints:

در Small Mobile (< 480px) نیز از right: 0.8rem به left: 0.8rem

4. نتیجه نهایی:
  • دکمه بستن در سمت چپ
  • عنوان در سمت راست بدون همپوشانی
  • مناسب برای محیط RTL فارسی
  • تمام سایزهای صفحه پشتیبانی می‌شود
