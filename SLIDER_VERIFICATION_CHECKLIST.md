## 🆘 TROUBLESHOOTING GUIDE

### If slides are empty:
1. Check console for errors
2. Run `articleSlider.verify()` in console
3. Inspect HTML structure (should have `.slider-slide` containers)
4. Check if CSS is loaded (`article-slider.css`)

### If navigation doesn't work:
1. Check if JS file is loaded (`article-slider.js`)
2. Check for JavaScript errors in console
3. Verify buttons have event listeners
4. Test with `articleSlider.nextSlide()` in console

### If cards don't fit properly:
1. Check browser window size
2. Inspect `.slider-slide` container (should be 100% width)
3. Inspect `.slider-card` (should be `flex: 1 1 0`)
4. Check for CSS conflicts
