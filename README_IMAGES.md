## 🚀 استفاده سریع

### فقط یک دستور:
```bash
cd h:\Repo\Hugo\davoodya
python convert_images.py
```

## ✅ این اسکریپت چه کار می‌کند؟

### 1️⃣ تبدیل فرمت
```markdown
# قبل
![[Pasted image 20260205202337.png]]

# بعد
![Pasted image 20260205202337.png](/images/cyber-security/Pasted image 20260205202337.png)
```

### 2️⃣ ایجاد دایرکتوری‌ها
```
static/images/
├── cyber-security/
├── python/
├── seo/
└── tools/
```

### 3️⃣ کپی تصاویر
```
از: H:\Files\Obsidian\Handouts\VaultData\Attachments\image.png
به:  static/images/category/image.png
```

### 4️⃣ ذخیره لاگ
```
processed_images.json           # تصاویر پردازش شده
image_conversion.log            # لاگ کامل
image_conversion_report.txt     # گزارش خلاصه
```

## 🎯 ویژگی‌های کلیدی

- ✅ **هوشمند**: تصاویر تکراری را دوباره پردازش نمی‌کند
- ✅ **سریع**: فقط تصاویر جدید را کپی می‌کند
- ✅ **امن**: از فضاهای خالی در path ها پشتیبانی می‌کند
- ✅ **دقیق**: دسته‌بندی را خودکار تشخیص می‌دهد
- ✅ **کامل**: لاگ و گزارش دقیق ایجاد می‌کند

## 🐛 عیب‌یابی

### مشکل: "دایرکتوری Obsidian پیدا نشد"
```python
# خط 18 را بررسی کنید:
OBSIDIAN_IMAGES_DIR = r"H:\Files\Obsidian\Handouts\VaultData\Attachments"
```

### مشکل: "تصویر کپی نشد"
- بررسی کنید تصویر در Obsidian وجود دارد
- مجوزهای فایل را بررسی کنید
- فضای دیسک را بررسی کنید

### مشکل: "خطای encoding"
- اسکریپت از UTF-8 استفاده می‌کند
- نام فایل‌های فارسی پشتیبانی می‌شوند
